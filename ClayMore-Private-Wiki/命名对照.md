# 私密库命名对照

这是 Private Wiki 的命名说明。业务目录以中文为主，知识库工程术语保留英文或中英混合，例如 `private-raw`、`private-assets`、`wiki`。

## 根目录文件

| Name | 中文备注 | Purpose |
|---|---|---|
| `000-私密首页.md` | 私密库主页 | 私密库入口。 |
| `AGENTS.md` | 私密库 LLM 维护规则 | 工具约定文件名，保留英文。 |
| `命名对照.md` | 命名对照表 | 文件和目录中文说明。 |

## 目录

| Name | 中文备注 | Purpose |
|---|---|---|
| `身份资料` | 身份证件索引 | 身份证件索引、位置、续期提醒。 |
| `账号索引` | 账号索引 | 账号用途、恢复路径、密码管理器引用。 |
| `私密财务` | 私密财务索引 | 私密财务索引和恢复信息。 |
| `健康` | 健康信息 | 健康史、医疗笔记和资料引用。 |
| `家庭` | 家庭信息 | 家庭和紧急事项。 |
| `应急恢复` | 应急恢复 | 应急清单和恢复流程。 |
| `法律文件` | 法律文件 | 法律文件索引和备注。 |
| `private-raw-私密原始资料` | private raw | 不应复制到主库的私密来源笔记。 |
| `private-assets-私密附件` | private assets | 只在存储位置受保护时使用。 |

## 安全说明

- `账号索引` 是索引，不是密码库。
- `身份资料` 避免记录完整证件号，除非存储位置已加密且确有必要。
- `private-raw-私密原始资料` 未经明确许可不要总结进主知识库。
