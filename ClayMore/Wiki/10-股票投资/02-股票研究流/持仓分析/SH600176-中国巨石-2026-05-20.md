# 中国巨石（600522）— 深度分析

报告日期：2026-05-20 | 数据截至：2026Q1 | 框架：7步法

---

## ⚖️ 总判

中国巨石正处于**AI算力驱动电子布超级景气周期**的正中央。2026Q1毛利率从2024年低点20.1%飙升至39.64%，归母净利+73.5%。核心引擎是电子布——7628型号从2025年9月的4.15元/米一路涨至2026年5月的6.5-6.8元/米，累计涨幅57-64%。织布机供给瓶颈（日本丰田排期到2028年）锁死了短期竞争扩产的可能性，涨价持续性有供给端硬约束。

核心矛盾：5月13日44亿扩产公告后5月15日跌停，市场在给"涨价→扩产→过剩"的历史周期律定价。但这次不同——扩产填补的是AI驱动的结构性缺口（电子布需求CAGR远超历史周期），而非简单的供给泛滥。

判断：**中长期买入逻辑成立，短期需消化扩产恐慌。** 当前PE(TTM) 36x已有相当预期计入，2026E前瞻PE约25x（基于一致预期53.6亿净利）在AI上游材料股中合理。最佳买点是等市场对扩产的过度担忧充分定价后的回调窗口。

---

## 第1步：看懂这家公司

### 它是做什么的？

中国巨石是全球最大的玻璃纤维企业，拥有浙江桐乡、江西九江、四川成都、江苏淮安、埃及、美国6大生产基地。全球市占率约25%，国内市占率约40%。三项"世界第一"：热固粗纱、热塑增强、电子基布。

### 它怎么赚钱？

收入结构（2026Q1）：粗纱81%（毛利率30%）、电子布18%（毛利率27%）、其他1%。粗纱走量、电子布走价。毛利率从2024Q1的20.1%攀升至2026Q1的39.64%，连续8个季度提升。净利率约25%。

核心成本优势来自三点：叶蜡石采购价440元/吨（同行580-640元）、天然气单耗比同行低20m³/吨、E6配方用石灰石替代昂贵的硼钙石，吨成本节省500-600元。这些优势竞争对手短期内无法复制。

### 增长靠什么？

| 增长曲线 | 时间维度 | 驱动力 |
|---------|:------:|--------|
| 电子布涨价 | 2026年 | 7628已涨57%至6.5-6.8元/米，织布机供给瓶颈锁死竞争 |
| 淮安新线放量 | 2026H2-2027 | 3月点火10万吨电子纱+3.9亿米电子布产线，全球最大单体 |
| AI算力电子布 | 2026-2028 | AI服务器PCB→覆铜板→电子布需求爆发，年增量1-4亿米 |
| 粗纱周期复苏 | 2026H2 | 行业供给增速降至5%以下，Q2长协复价预期 |
| 海外产能扩张 | 2027+ | 埃及36万吨+美国9.6万吨规避关税 |

### 有没有护城河？

| 类型 | 评级 | 理由 |
|------|:----:|------|
| 规模效应 | ⭐⭐⭐⭐⭐ | 粗纱产能289万吨+电子布9.6亿米，均为全球第一 |
| 成本优势 | ⭐⭐⭐⭐⭐ | 叶蜡石自控+配方领先+天然气单耗低，吨成本低同行15-20% |
| 技术壁垒 | ⭐⭐⭐⭐ | E6/E7/E8配方体系、低介电电子布技术，但极高端仍有差距 |
| 转换成本 | ⭐⭐⭐ | 电子布需通过覆铜板厂商认证，周期6-12个月，但非不可替代 |
| 全球化布局 | ⭐⭐⭐⭐ | 埃及+美国双海外基地，规避贸易壁垒 |
| **综合护城河** | **⭐⭐⭐⭐** | **宽护城河，成本+规模+全球化三重壁垒** |

### ☠️ 最大风险

**电子布"涨价→扩产→过剩"的历史周期律重演。** 这是5月15日跌停的根本原因。行业在建/拟建项目投资额达134亿元。关键变量是织布机供给瓶颈——全球高端喷气织机年供应仅1800-2000台、日本丰田排期到2028年——这让新产能的实际落地时间可能比公告的更长。如果这个瓶颈确实存在，2027年底前电子布供需缺口难以弥合，涨价持续性就有支撑。如果织布机瓶颈被证伪（中国厂商突破或日系加速供货），过剩会更早到来。

## 第6步：决策清单

### ✅ 买入/持有的理由

1. **电子布超级景气周期有供给端硬约束** — 织布机排期到2028年，短期产能无法快速释放，涨价持续性有保障
2. **Q1利润+73%已验证弹性** — 毛利率39.6%创近年新高，现金流42亿真金白银
3. **AI算力+新能源+风电三重需求叠加** — 电子布（AI PCB）、热塑纱（新能源车）、风电纱都处于需求上行期
4. **成本优势是永续护城河** — 吨成本比同行低15-20%，周期底部也亏不过同行，龙头地位稳固
5. **前瞻PE 25x在AI上游材料中偏低** — 如果2026年兑现54亿净利，当前估值有支撑

### ❌ 不买/卖出的理由

1. **52周涨268%已有大量预期计入** — 当前价位追高安全边际不足
2. **44亿扩产引发市场分歧** — 5月15日跌停说明多空博弈激烈，短期方向不明
3. **非AI直接受益标的** — 公司明确表示"没有直接和AI服务器企业有业务往来"，概念纯度低
4. **应收账款+66%+有息负债83亿** — 扩张期的财务质量在恶化
5. **电子布竞争格局不如粗纱稳固** — 国际复材（低介电市占35%）、宏和科技（4μm通过英伟达认证）在高端领域构成威胁

### 与其他持仓/关注标的的关系

```
AI产业链完整度：
电子布(巨石) → PCB(深南电路) → 服务器(工业富联/紫光/曙光) → 数据中心电源(科士达/科华)
```

> 中国巨石填补了你组合中"AI上游材料"的空白。工业富联、紫光股份是AI服务器的直接玩家，而巨石是更上游的"卖铲人"——不管谁赢，都要用电子布做PCB。

### 建仓节奏建议

> 不在跌停后立即抄底（情绪未释放完），也不在35元附近追高（离目标均价太近）。分3批建仓：第一批等待MA20（~32.5元）附近企稳后试探（3%仓位），第二批等Q2业绩预告或粗纱复价落地后追加（+3%），第三批等电子布突破8元+逻辑强化后完成（+2%）。如果直接突破40元放量，放弃追高。
