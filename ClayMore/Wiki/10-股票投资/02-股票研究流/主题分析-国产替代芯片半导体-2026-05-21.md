# 主题分析：国产替代 + 芯片半导体（排除科创板）

报告日期：2026-05-21 | 视角：国产替代和芯片半导体两条主线 | 范围：持仓11只 + 自选池非科创板半导体相关标的

---

## 一、先说结论：排除科创板后，你的半导体暴露集中在产业链中下游

科创板（688xxx）聚集了A股最纯正的国产替代标的——半导体设备（中微公司、华海清科、芯源微）、晶圆制造（中芯国际、华虹公司）、高端芯片设计（海光信息、澜起科技）、电子特气（华特气体、中船特气）——这些全部是688开头。

排除科创板后，你的芯片半导体布局集中在三个非科创环节：封测、功率半导体、和PCB/光器件。这三个环节恰好是国产替代相对成熟、商业化程度更高的领域。

这是一个重要的结构特征：你在"国产替代最难啃的骨头"（设备、制造、高端设计）上没有直接暴露，但在"国产替代已验证的环节"（封测、功率器件、材料）上暴露充分。

---

## 二、持仓端：11只中7只直接踩在主题上

### 封测三只 — 国产替代最成熟的半导体环节

封测是中国半导体国产化率最高的环节，长电科技全球第三、通富微电全球第四。这个子赛道的国产替代故事不是"能不能替代"，而是"替代到什么程度，赚多少钱"。

| 标的   | 定位       | 国产替代逻辑                                        |
| ---- | -------- | --------------------------------------------- |
| 长电科技 | 规模+技术护城河 | 国内封测技术最前沿（2.5D量产+CPO储备），100亿资本开支遏制海外OSAT向国内转移 |
| 通富微电 | 成长弹性     | 绑定AMD但受益于先进封装产能向中国集中，经营现金流70亿验证模式健康           |
| 华天科技 | 待换仓      | 净利率1.6%不支撑"国产替代龙头"的叙事，PE 135倍是情绪溢价而非基本面溢价     |

封测环节的国产替代逻辑没有问题——三只合计覆盖了国内封测的大部分产能。问题只是华天科技在赛道内相对竞争力太弱。

### 三安光电 — 化合物半导体的国产替代孤例

三安是国内唯一能量产SiC衬底+器件的IDM，在化合物半导体国产替代中位置独特。Q1营收-33%和全年预亏说明商业化的路还很长，但SiC的国产替代方向本身没有错。决定它去留的不是"是不是国产替代"，而是"亏损何时结束"。

### 中国长城 — 信创国产替代的政策性标的

信创（党政军IT系统国产化）是最典型的政策驱动型国产替代。中国长城搭载飞腾CPU的国产电脑和服务器，在党政信创市场有60%+份额，护城河直接来自政策壁垒而非技术领先。CPU性能与Intel/AMD仍有代差，但在"能用就行"的信创场景中，政策的排他性足以构成壁垒。核心矛盾仍是扭亏时点。

### TCL中环 — 半导体硅片国产替代的隐性期权

市场看TCL中环主要看光伏硅片，但它的半导体材料业务（国内半导体硅片出货第一、12英寸大硅片）是独立于光伏的国产替代逻辑。只是半导体业务当前体量小（14.4亿营收，占总收入约22%），短期不是股价主要驱动。把它放在"国产替代"框架下看，它的价值被光伏亏损遮蔽了。

### 工业富联 — 主题边缘

全球最大AI服务器组装商，但台资背景+代工属性决定了它不是"国产替代"叙事的主角。它受益于AI算力需求，但受益机制是"全球算力建设需要更多服务器"，不是"用国产替代进口"。

### 光缆两只 + 养元饮品 — 不在此主题内

亨通和中天受益于AI数据中心互联（光纤需求），但光缆的国产化率已经极高，不存在"替代"故事。养元是完全独立的消费标的。

### 科创芯片ETF（SH588200）— 科创板芯片，但你要排除科创板

这只ETF跟踪的是上证科创板芯片指数，底层全是688xxx。既然你这次明确排除科创板，它在这轮主题分析中就是一个矛盾体——你想通过ETF间接持有科创芯片暴露，但又不想直接碰科创板。这个矛盾需要你自己厘清：要么接受ETF作为科创板的间接敞口，要么换一只非科创的芯片ETF（如159665半导体龙头ETF，但那是场外基金）。

## 四、你的国产替代链条完整度

如果画一条从上游到下游的国产替代产业链：

```
硅片(TCL中环半导体业务) → 设备(北方华创) → 设计(兆易/斯达/士兰微) → 制造(缺，全在科创板) 
→ 封测(长电/通富/华天) → PCB(深南/沪电) → 光器件(光迅/天孚) → 服务器组装(工业富联/曙光)
→ 信创终端(中国长城)
```

链条中三个关键缺口：
- **晶圆制造**：全在科创板（中芯国际688981、华虹688347），非科创无覆盖
- **高端芯片设计**：CPU/GPU在科创板（海光688041），非科创只有功率和MCU
- **半导体设备**：除北方华创外全在科创板

这不是需要填补的问题——这是A股市场结构决定的：科创板就是为半导体硬科技企业设立的。非科创板的半导体标的天然偏向成熟环节（封测、PCB、功率器件、光纤）。

## 七、结构性问题与建议

**1. 封测暴露过重。** 持仓中封测三只 + 自选中再无封测，这不是缺少覆盖，而是覆盖过度。华天换仓执行后，封测缩至长电+通富两只，表达已经足够。

**2. 功率半导体三选一。** 自选中斯达半导、士兰微、新洁能都属功率器件，但你的持仓中没有直接功率半导体暴露（三安的SiC算半个）。如果要在功率方向加仓，斯达半导的IGBT+SiC逻辑最强（虽有Q1阵痛），但不要在士兰微和新洁能上同时押注，避免同向波动。

**3. 科创芯片ETF与"排除科创板"的矛盾需要解决。** SH588200跟踪的是上证科创板芯片指数，底层全是688xxx。如果你想表达芯片半导体观点又不碰科创板，可以考虑替换为：
- 兆易创新（个股，非科创芯片设计）
- 深南电路（个股，PCB）
- 或者接受ETF作为科创板的间接工具型敞口

**4. 设备+制造环节的空白是由A股结构决定的，不是策略缺陷。** 中微公司、中芯国际、海光信息在科创板，你排除科创板后自然覆盖不到。如果未来这个约束放开，这三个是最值得优先考虑的。

**5. 中科曙光是最契合当前主题的标的。** 国产算力底座+海光CPU绑定+超算国家队，完美踩中国产替代和AI算力两条线。如果你已清仓浪潮信息，中科曙光是同一赛道的升级替代，逻辑也更硬。
