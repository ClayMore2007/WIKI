# 板块优质股票速查表

> 本页用于把当前股票资料、自选池、旧持仓板块和公司名频率表合并成“按板块找公司”的速查入口。资料中大量内容来自个人笔记、社媒视频和机器转写，默认低置信；公司出现频率只代表资料出现，不代表供应链、订单、业绩或投资结论已经核验。本页不构成投资建议。

## 脑图入口

- [[Wiki/10-股票投资/板块优质股票速查表-看板.canvas|板块优质股票速查表-看板]]

> 看板已补充价格和财务速查字段：价格取同花顺本地记录价；最近季度营收同比、归母净利润同比取东方财富数据中心 `2026Q1 / 2026-03-31` 财报数据；PE(TTM) 取东方财富估值分析 `2026-05-29` 交易日数据。字段仅用于快速筛选，进入交易判断前必须回公告、财报和行情源二次核验。

## 使用方式

| 字段 | 含义 |
|---|---|
| 主线 | 先按投资主线找板块，而不是按普通行业大类找股票 |
| 环节 | 在产业链中定位公司角色，便于横向比较 |
| 优先级 | P0 为资料反复出现/龙头线索/持仓或候选重点；P1 为核心观察；P2 为补充观察；P3 为暂存线索 |
| 价 | 看板中的同花顺本地记录价；`--` 表示本次本地价格源未取到 |
| 资料热度 | 来自 [[公司名出现频率总表]] 的出现次数；0 表示未进入标黄频率表或未命中 |
