# 股票分析框架

这里存放股票分析的通用模板、示例案例和后续可复用的方法论。用于把单只股票研究统一成“事实 / 假设 / 风险 / 触发条件 / 复盘”的结构，避免只看短期行情或单一视频结论。

## 使用方式

1. 新分析一只股票时，复制 [[Wiki/10-股票投资/02-股票研究流/分析框架/股票深度分析模板-7步法]] 到 `Wiki/10-股票投资/02-股票研究流/公司档案/`。
2. 文件名建议使用 `公司名-股票代码-深度分析`。
3. 填写时参考 [[Wiki/10-股票投资/02-股票研究流/分析框架/案例-中天科技-600522-7步法]] 的结构，但每个数据点都要补来源。
4. 完成后，把核心结论和下次复盘时间同步到 [[Wiki/10-股票投资/03-交易判断/持仓处理清单]]。
5. 如果来源是同花顺、券商软件或第三方 AI 生成的“个股诊断/快诊报告”，先按“事实 / 指标 / 模型 / 结论”拆解，全部标注来源和待核验，再决定是否进入完整 7 步法。

## 维护规则

- 股票分析默认是高风险内容，必须保留来源、日期和不确定性。
- 案例中的财务、估值和价格数据会过期，正式决策前必须回到公告、财报、行情软件或研报复核。
- “总判”和“最终结论”必须能被“风险排查”和“触发条件”反驳，不写单边乐观结论。
- 第三方 AI 报告中的专有指标（如区间、共振、资金线、活跃线）只作为线索，必须记录指标定义、截图时间、数据口径和后续走势复盘；不能写成已验证事实。
