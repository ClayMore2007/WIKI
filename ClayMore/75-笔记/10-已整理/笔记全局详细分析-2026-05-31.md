## 3. 主题结构

### 3.1 交易动作层：卖出优先于买入

从笔记结构看，卖出相关内容明显多于买入相关内容。2026-05-17 到 2026-05-21 的主轴是“处理持仓”，包括：

- 准备卖出：浪潮信息、盈峰环境、华天科技、合肥城建、永鼎股份
- 已卖出：亨通光电、兴业银锡、三安光电、天通股份、华天科技
- 明确卖出/待定：富通微电、特变电工、浪潮信息、TCL中环、养元饮品、三安光电等

这说明你的交易状态当时不是“从零筛选新机会”，而是先做仓位腾挪和风险清理。这个阶段最重要的不是选新票，而是确认每个卖出动作背后的理由是否足够硬。

待补问题：

- 哪些是基本面恶化导致卖出？
- 哪些是估值/涨幅过高导致止盈？
- 哪些只是短线情绪或仓位压力？
- 卖出后是否有复盘：卖对了、卖早了、还是卖错了？

### 3.2 买入观察层：偏科技，但开始补消费

买入侧一开始明显偏科技：

- 科创芯片相关、科创50ETF
- 长电科技、科创芯片ETF
- 晶方科技
- 特变电工低位观察
- 商业航天线索：*ST铖昌

到 2026-05-31，出现“消费板块会上涨”的判断。这是一个重要变化：它说明你的主线视野从科技成长扩展到消费/老登股/顺周期或防守方向。

但买入侧目前有一个共同问题：多数条目还停留在“方向/意向”，缺少触发条件。

建议后续每个买入候选都补 4 个字段：

| 字段 | 作用 |
|---|---|
| 买入逻辑 | 为什么是它，而不是同板块其他票 |
| 触发条件 | 什么价格、形态、事件或业绩确认后才买 |
| 失效条件 | 逻辑被什么信号证伪 |
| 计划仓位 | 试错仓、标准仓、重仓分别对应什么证据 |

### 3.3 行业主线层：半导体是主轴，电力/算电协同是延伸

行业观察里，半导体相关笔记最密集。关键词包括：

- 存储
- 先进封装
- 华为韬定律
- 功率半导体
- 光刻胶、电镀液、抛光液
- MLCC、钽电容
- 半导体产业链 Top 清单

这说明你的主线框架大致是：

```text
AI / 国产替代 / 华为逻辑
→ 存储、先进封装、功率半导体、材料
→ MLCC、钽电容等被 AI 需求带动的电子元器件
```

随后你把视野从“算”延伸到“电”：

```text
算力需求
→ 数据中心 / 算电协同
→ 电力、储能、绿电、配电、UPS
```

这个延伸是有一致性的：它不是随机换题材，而是从 AI 算力的瓶颈向上游和基础设施推导。但目前仍是“逻辑链条”，不是已核验事实链条。

待核验重点：

- 存储、先进封装和 MLCC 的景气是否已经反映在订单、价格和财报中？
- 算电协同相关订单是否真实来自 AI 算力中心，而不是普通电网/储能项目被主题化包装？
- 储能方向的毛利率和订单是否可持续？
- 华为相关叙事是否有公告、供应链验证或业绩兑现，而不只是概念扩散？

### 3.4 市场判断层：从“科技回调”到“老登股/消费”

市场判断部分出现了几个阶段性看法：

- 两周内指数新高，随时撤离
- 6 月第一周上半周科技回调动荡，可能破新低；下半周老邓股上涨直到破新高
- 券商比较确定要涨，白酒有可能
- 后续主要是消费板块会上涨

这里有一个很明显的轮动判断：

```text
科技主线高波动 / 可能回调
→ 老登股承接
→ 券商、白酒、消费板块成为后续方向
```

这类判断适合沉淀为“市场节奏假设”，但不能直接变成交易动作。原因是它涉及指数、风格、资金面和板块轮动，需要明确验证指标。

建议给每个市场判断补三个验证点：

- 指数位置：是否突破/回踩关键点位？
- 资金流向：科技、券商、白酒、消费之间是否真的发生切换？
- 板块强度：消费是普涨、防守轮动，还是有具体龙头带动？

## 4. 行为模式分析

### 4.1 优点：能快速形成主线和候选池

你的笔记有一个强优势：反应速度快。看到方向后，会迅速把行业、个股、交易原则和后续处理放到一起。

表现为：

- 能从个股扩展到产业链
- 能从半导体扩展到材料、封装、电力、储能
- 能在交易中不断总结原则
- 能及时记录“卖出/待定/关注/特别关注”

这说明你的投资思考不是孤立看 K 线，而是试图建立主线地图。

### 4.2 风险：切换速度快，容易让判断之间互相冲突

风险也很明显：方向切换很快。

例如：

- 一边强调科技/半导体/存储/先进封装还有机会
- 一边又判断科技回调、老登股上涨、消费板块后续上涨
- 一边想要重仓有信心的票
- 一边又有大量卖出/必卖/待定动作

这些判断不一定矛盾，但需要分层：

| 层级 | 应该回答的问题 |
|---|---|
| 大盘/风格 | 现在适合进攻还是防守？ |
| 行业主线 | 科技、消费、电力谁是主线，谁是轮动？ |
| 个股选择 | 同一主线里哪个票最强？ |
| 交易动作 | 什么时候买、什么时候卖、仓位多少？ |

如果不分层，容易出现“方向都看好，但交易上互相打架”的问题。

### 4.3 风险：部分笔记缺少时间条件

不少判断用了“后续”“后期”“明天”“随时”“可能”等词。这些词适合快记，但不适合直接执行。

需要补成可复盘语言：

| 原始表达 | 建议补充 |
|---|---|
| 后期还有上涨空间 | 观察周期是几天、几周还是一个季度？ |
| 明天买入 | 明天是自然日还是下一个交易日？开盘买还是回调买？ |
| 随时撤离 | 跌破什么位置、放量滞涨还是指数新高后撤？ |
| 会上涨 | 是板块指数上涨、龙头上涨，还是补涨扩散？ |

目前这条线笔记少，但位置重要：它可能代表你对科技高波动之后市场风格切换的判断。建议先不要直接扩成很多个股，而是先建立“消费/老登股观察框架”。

## 6. 当前组合管理问题

从卖出、准备卖出和关注清单看，你的组合管理有三个待解决问题。

### 6.1 持仓处理理由需要统一

目前同一个票可能在不同阶段出现“卖出、待定、关注、特别关注”等状态。建议统一成一张状态表：

| 状态  | 含义               |
| --- | ---------------- |
| 必卖  | 逻辑已失效，等待卖点       |
| 减仓  | 逻辑未失效但估值/涨幅/风险过高 |
| 观察  | 暂不交易，只跟踪验证       |
| 候选  | 逻辑待核验，未进入买入计划    |
| 可买  | 已有触发条件和仓位计划      |

### 6.2 买入候选需要和卖出资金对应

卖出动作很多，但买入候选没有明确承接关系。

建议每次卖出后记录：

- 卖出释放多少仓位
- 是转向科技、消费、电力，还是留现金
- 买入候选的优先级
- 若没有更高胜率标的，是否允许空仓等待

### 6.3 “重仓”规则需要前置条件

“有信心的股票，买入和补仓要果断重仓”是一个重要交易原则，但需要防止它变成情绪放大器。

建议改写为：

> 只有当主线、个股、买点、风险控制、仓位上限都明确时，才允许果断重仓；如果只是题材看好或短线情绪强，不算“有信心”。

## 8. 下一步行动清单

建议按优先级处理，不要同时铺太多线。

1. 先整理持仓处理清单：把必卖、待定、观察、候选状态统一，避免同一标的多处状态冲突。
2. 给市场风格切换假设建验证框架：科技是否回调、消费/券商/白酒是否接力，用指数和板块强度确认。
3. 给半导体主线做证据表：存储、先进封装、MLCC、功率半导体分别列事实证据和待核验点。
4. 给算电协同/储能做订单真实性核验：区分真实 AI 算力需求、普通电网项目和概念包装。
5. 把“重仓规则”拆成可执行条件：主线确认、个股确认、买点确认、止损确认、仓位上限确认。
6. 对 2026-05-17 至 2026-05-21 的密集卖出做一次回头复盘：哪些卖对，哪些卖早，哪些卖错。

## 9. 总结判断

这批零散笔记最有价值的地方，不是某一个具体个股判断，而是暴露出你的交易系统正在形成三个模块：

- **主线发现模块**：能快速从科技、半导体、AI 硬件扩展到电力、储能、消费。
- **组合调整模块**：会主动清理不想持有的票，并建立关注/特别关注/候选池。
- **交易纪律模块**：开始反复记录择时、复盘、风控、重仓条件。

当前最需要补齐的是“验证模块”。也就是每个判断都要能回答：

- 这个判断什么时候算对？
- 什么信号出现后算错？
- 如果对了，买谁、怎么买、买多少？
- 如果错了，何时撤、怎么撤？

只要把这个验证模块补上，这批笔记就能从“即时想法”升级成“可复盘的交易系统”。
