# 每日复盘

这里存放每日复盘记录。

## 使用方式

- 用户提到“复盘”且没有指定其他去向时，默认把对应内容保存到这里。
- 每日复盘按年份分目录，文件名使用 `YYYY-MM-DD.md`。
- 保存每日复盘后，同步追加一句摘要到 [[复盘汇总]]。
- 如果用户明确说“周复盘”，则更新 [[003-周复盘]]。
- 如果复盘内容已经沉淀成稳定知识、问题或决策，再整理到对应 `Wiki/` 页面。
