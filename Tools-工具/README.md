# Tools-工具

本目录存放 Obsidia 工作区的本机工具、脚本和安装说明。

## 目录说明

- `automations/`：本机自动化任务说明，例如空闲自动提交和微信通知。
- `openclaw/`：OpenClaw、Weixin、Codex 连接相关配置和修复脚本。
- `video/`：视频内容提取技能和脚本。
- `openclaw-logs/`：本机 OpenClaw 日志目录，已在 `.gitignore` 中忽略。
